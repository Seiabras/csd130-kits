# Mapa de notas da CSD130

A nota MIDI que cada pad manda pelo USB. Serve para o modo computador: o programa (DrumGizmo, Hydrogen) precisa
saber qual nota é qual peça.

Como preencher: `ferramentas/ler-pads.sh`, bater em cada pad e anotar a nota. O manual não traz este mapa; a lista
GM das págs. 36 e 37 é a do som que o módulo toca quando **recebe** cada nota, que pode não ser a que ele manda.

| Caixa | a conferir | 38 | |
